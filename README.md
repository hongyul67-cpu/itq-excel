# ITQ 엑셀

한글엑셀(과목코드 1122) 실기 대비 — 네 장의 작업 시트가 무엇이고 배점이 어떻게 나뉘는지 먼저 배우고,
기능별 문항을 풀고, 실습 세트 A~E 를 체크리스트로 따라 하며 통합 문서 한 벌을 완성하는 학습도구.

- 주소 : https://hongyul67-cpu.github.io/itq-excel/
- 대상 : 화요일 1~2교시 ITQ 수업 (고등학교)
- 만든 날 : 2026-09-03

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 배우기 → 연습 8문항 → 실습 세트 → 종합시험 20문항 → 오답노트 → 제출 |
| `lesson.js` | 📽️ 수업 슬라이드 원고 26장. 화면은 links 의 공용 `board-pro.js` 가 그린다 |
| `rubric.json` | 결과수집이 세특 문장·성취수준을 만들 때 쓰는 평가 루브릭 |

## 화면

교실 앞에 띄우는 **📽️ 수업 슬라이드**(26장)는 배우기 탭 아래의 「수업 슬라이드 열기」로 엽니다.

| 탭 | 내용 |
|---|---|
| 📖 배우기 | 배점표(제1작업 240 / 제2·3작업 각 80 / 제4작업 100) · 답안 작성요령 · 유형 01~07 |
| ✏️ 연습 8문항 | 고르는 즉시 정답·해설 공개 |
| 🧪 실습 세트 | A 답안 준비 / B 표 서식 / C 값 계산 / D 제2·제3작업 / E 그래프 |
| 🏁 종합시험 20문항 | 채점은 마지막에. 끝난 뒤 오답노트 |
| 📕 오답노트 | 이 기기에 쌓인 오답 |
